# Archive — history, not rules

Finished research reports, implementation ledgers, handoffs and reviews, kept for their evidence and reasoning. Nothing here is a rule: each file opens with a **Historical** banner that names its live contract, and a live doc never cites this folder as the source of a rule (`ArchiveCitationTests`).

The live contract is [gameplay-spec.md](../gameplay-spec.md) and the docs [AGENTS.md](../../AGENTS.md) names; what is shipped and open is [status.md](../status.md); the accepted decision plans are in [decisions/](../decisions/).
