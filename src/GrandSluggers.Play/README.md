# GrandSluggers.Play — debug sandbox

Raylib 3D window for poking `GrandSluggers.Sim`. **Not the game.**

How you play: open `unity/` in Unity **6000.5.9f1** and press Play on `Assets/Scenes/HarborDiamond.unity`. See [unity/README.md](../../unity/README.md).

Do **not** add HUD keys, VFX, parks, cameras, or bodies here. New presentation lands only under `unity/`.

```bash
PATH=/opt/homebrew/bin:$PATH dotnet run --project src/GrandSluggers.Play
```
